Questions

你可能想问

我的数据保存在哪里？安全吗？+

全部保存在你手机本地的数据库里：人物、提醒、对话、长期记忆、图片附件都是。TaWorld 没有自建业务服务器，不存在「云端数据库泄露」的问题；你可以随时完整备份，也随时可以删除。

应用会自动帮我去联系对方吗？+

永远不会。这是 TaWorld 的第一原则：人是连接的桥梁。它只提醒你、建议你、帮你记住，发送消息的行动永远由你亲自完成。

需要联网吗？AI 要额外付费吗？+

提醒调度、人物管理、图谱与成就完全本地运行；AI 对话与天气查询需要网络，由设备直接请求对应服务。AI 功能使用你自己的 DeepSeek API Key（首次启动引导页可填，也可稍后在设置中配置），费用由你与服务商直接结算，不经任何中间方。

支持 iPhone 吗？+

目前以 Android 优先。项目使用 Flutter 开发，跨平台在技术路线之内，iOS 动态请关注 GitHub 仓库。

换了手机，数据怎么迁移？+

在旧手机「设置 · 备份」生成备份文件（包含数据库与图片附件），新手机导入即可。导入前会做结构与路径校验，失败自动回滚，不会破坏现有数据；备份文件也可以经微信、QQ 转发后直接用 TaWorld 打开。

应用收费吗？有广告吗？+

免费、无广告、无内购。源码在 GitHub 公开，欢迎 star、提出建议或参与共建。
