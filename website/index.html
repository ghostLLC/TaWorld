Memory · 核心亮点

有记忆的 AI，
才是真的懂你

不是每次聊天都从零开始。TaWorld 参考 human memory 的分层方式设计记忆系统：重要的事刻进长期记忆，日常对话留存在情景记忆里，时间久了自动整理——像朋友一样，越处越默契。

📖

Wiki 事实记忆

从对话中自动提取关于 Ta 的重要事实——生日、喜好、忌口、最近的烦恼——结构化长期保存，每次对话都会带上。

🔍

RAG 情景召回

过往对话按主题分块存储，聊到相关话题时自动检索。「上次你说 Ta 胃不舒服，最近好些了吗？」——AI 帮你自然接上之前的关心。

📝

自动对话摘要

对话变长时自动总结为精炼摘要，既不丢失重要信息，也不会让记忆无限膨胀。

🌙

Dreamer 记忆整理

像人在睡眠中巩固记忆一样，AI 会在后台自动整理：弱化过时细节、合并重复内容、巩固关键信息。

Privacy · 产品原则

人是连接的桥梁，
隐私是关怀的底线

TaWorld 永远不会代替你联系任何人，也永远不会把你的数据上传到任何服务器。AI 只负责提醒你、建议你、帮你记住——关心的行动，永远由你亲自完成。

人是桥梁

TaWorld 提醒 A 去关心 B，绝不会直接联系 B。

本地优先

人物、提醒、对话与记忆全部存在设备本地 SQLite 中。

主动不打扰

结合时区、天气与提醒状态，只在合适时机出声。

简洁可解释

关键操作有明确反馈，AI 工具执行结果可追踪。

FAQ · 常见问题

你可能想问

我的数据保存在哪里？安全吗？

全部保存在你手机本地的 SQLite 数据库里：人物、提醒、对话、长期记忆、图片附件都是。TaWorld 没有自建业务服务器，不存在「云端数据库泄露」的问题。你可以随时在应用内完整备份，也随时可以删除。

应用会自动帮我去联系对方吗？

永远不会。这是 TaWorld 的第一原则：人是连接的桥梁。它只提醒你、建议你、帮你记住，发送消息的行动永远由你亲自完成。

需要联网吗？AI 要额外付费吗？

提醒调度、人物管理、图谱、成就等功能完全本地运行；AI 对话与天气查询需要网络，由设备直接请求对应服务。AI 功能需要你自己的 DeepSeek API Key（首次启动引导页可填，也可以稍后在设置中配置），费用直接由你与服务商结算，不经任何中间方。

支持 iPhone 吗？

目前以 Android 优先（项目使用 Flutter 开发，跨平台在技术路线内），iOS 版本请关注 GitHub 仓库动态。

换了手机，数据怎么迁移？

在旧手机「设置 → 备份」生成备份文件（包含数据库与图片附件），新手机导入即可。导入前会做结构与路径校验，万一失败会自动回滚，不会破坏现有数据；备份文件也可以通过微信 / QQ 转发后直接用 TaWorld 打开。

应用收费吗？有广告吗？

免费、无广告、无内购。源码在 GitHub 公开，欢迎 Star、提 Issue 与参与共建。
