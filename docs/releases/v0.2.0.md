# TaWorld v0.2.0 · 多模态与体验可靠性

发布日期：2026-10-28

版本：`0.2.0+4`

## 摘要

本版统一 `deepseek-flash` 多模态模型入口，完善人物、提醒、通知与备份的可靠性，修复主题对比度、暗色一致性、信息层级、触控和动效问题，并将项目文档整理为现行指南与历史归档。

## 主要改动

- **单一多模态模型**：文字对话、图片理解、主动关心和记忆处理统一使用 `deepseek-flash`，移除独立视觉模型与 Pro 路由。
- **数据与地点**：损坏提醒隔离、人物恢复、字段清空、城市变更和可靠时区；列表与图谱不再按经度估算时间。
- **产品正确性**：数据重置清除身份与附件并回到首次引导；自定义提醒在创建和编辑时持久化可靠时间基准；历史长期日期按设备本地时区显示；人物统计与关怀建议使用中性、准确表述。
- **AI 工作流**：最多 6 轮依赖工具调用、写后验证、请求去重、取消、超时与部分成功反馈。
- **提醒闭环**：Android 原生定时发布、通知按钮、稳定 ID、差量排程、重启恢复和系统证据账本。
- **图谱与输入**：搜索筛选、稳定布局、拖动持久化、全屏、多页海报、语音与图片输入。
- **前端体验**：五套主题高对比语义前景、暗色一致性、48px 常用触控目标、精简小念首屏、提醒配置分层、受控 stagger 与减少动态效果。
- **隐私与备份**：API Key 使用平台安全存储且不进入备份；附件校验、导入回滚和通知状态重建。
- **工程与文档**：统一 AGENTS、现行文档索引、测试指南和发布说明；旧后端及研究资料集中归档；补齐 MIT LICENSE。
