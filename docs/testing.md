# TaWorld 验证与测试指南

## 1. 统一命令

从仓库根目录使用统一入口：

```bash
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tool/taworld.ps1 analyze --no-pub
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tool/taworld.ps1 test --no-pub
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tool/taworld.ps1 build apk --release --no-pub --split-per-abi
```

环境版本与代理规则见 `development_environment.md`。发布前必须依次通过静态分析、完整测试和三 ABI 构建。

## 3. 覆盖范围

### 数据与备份

- schema v1→v7 迁移、外键、损坏提醒隔离、人物软删除与恢复；
- 备份结构、附件路径、大小限制、恶意归档、导入回滚和密钥排除；
- 数据重置清除用户、偏好和受管附件，不留下绕过首次引导的空白用户。

### AI 与模型

- 单一 `deepseek-flash` 路由和多模态图片 payload；
- 工具依赖、多轮调用、参数修复、重名消歧、重试去重、取消和部分成功；
- 记忆提示、摘要 cutoff、主动关心证据约束。

### 提醒与后台

- 时区、DST、单次/每日/指定星期、损坏配置；
- 自定义提醒创建与编辑返回 timezoneMode，未确认人物时区时只能使用用户时间；单次提醒按人物时区显示且不改变原 UTC 时刻；
- 未来与长期提醒时间按设备本地时区显示；
- 稳定 ID、差量调度、进程锁恢复、重启恢复、稍后提醒和通知事件；
- 只计算明确确认的关心统计与成就进度。

### UI 与可访问性

- 图谱布局、390px、深色、200% 字体和海报分页；
- 五套浅色主题语义前景对比度至少 4.5:1；
- 48px 图标按钮、暗色阴影、语义组件色和进度环重绘；
- 小念操作菜单、健康卡显隐、提醒配置两行摘要；
- stagger 上限、减少动态效果和成就首次静默基线。

## 4. 修改时的测试要求

- 行为变化先更新或新增能复现问题的测试，观察其失败后再实现。
- 定向测试通过后必须运行完整测试，不能只验证当前文件。
- 数据迁移、备份、时区/DST、工具重试和原生通知属于高风险回归面。
- 页面修改至少检查当前主题、暗色、长文本、窄屏和大字体。
- 动画修改同时检查正常模式和 `disableAnimations`。

## 5. 证据边界

AI 协议测试使用受控响应，不能替代真实模型账户、权限、图片理解质量和固定任务集验证。自动测试也不能证明所有 Android 厂商后台策略、连续 72 小时通知表现或最终视觉效果。

用户验收是产品使用结论，不等于自动测试新增了真实模型、全部真机或长时间后台覆盖。发布说明必须区分这些证据，不能笼统写成“全部场景已验证”。
